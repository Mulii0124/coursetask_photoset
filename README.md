## 视觉与动效规则

- **影像节奏**：全站仅首屏与「重点故事」使用满屏影像；其余区块每屏最多一张主图，
  拼贴不超过两张。影像密集区之间插入纯文字或大留白章节，形成
  「影像—留白—文字—影像」的阅读节奏。
- **首屏推页**：首屏使用 `position: sticky` 固定在视口内，下一内容区从底部上推覆盖它。
- **图片切换**：系列目录切换时，旧图以 `scaleY(1)→0`（变换原点在上边缘）向上收缩，
  新图以 `scaleY(0)→1`（变换原点在底边缘）从底部展开。
- **文字进入**：所有文字与内容通过 `clip-path: inset()` 裁切进入，
  不使用普通淡入，也不使用 3D 翻页。
- **翻页**：页面之间用竖向幕布擦除（`scaleY`）衔接，而非淡出淡入。

## 资源与路径

- 所有页面之间的链接、图片、CSS / JS / 字体引用**一律使用相对路径**，
  不含本机绝对路径，也不含 `file://`。
- 页面内**不存在任何绝对 URL**：没有 `http(s)://` 外链，也没有 `mailto:`。
  邮箱与仓库地址在 HTML 里是页内锚点与纯文本，由 `assets/js/site.js` 在点击时
  组装邮件客户端链接；仓库地址通过「复制」按钮取用。
- 字体自托管于 `assets/fonts/`（Anton、Archivo、Noto Serif SC），不依赖外部 CDN。
- 页面结构清晰、标签使用规范；每个 `img` 都带 `width` / `height`，避免布局跳动。
- `.gitattributes` 规定所有文本资源以 LF 存储，网页源码在仓库与线上完全一致。

## 素材处理

原始照片来自本人拍摄的原片，存放于 `D:\photo`。`tools/` 中的脚本完成了全部素材整理：

- `tools/build_assets.py` — 扫描原片目录，按系列挑选并重新编号，
  统一施加一次对比度 / 饱和度校准（让两台机器、两个年份的素材看起来像同一次展览），
  输出 1800px / 1400px / 2600px 三档网页用渐进式 JPEG，
  同时生成 24px 模糊占位图。
- `tools/build_site.py` — 由结构化数据生成全部 10 个页面，
  保证导航、页脚、图注与元数据在每个页面完全一致。
- `tools/audit_site.py` — 交付前自检：检查所有引用是否为相对路径、
  目标文件是否存在、每个页面是否能从 `index.html` 到达。

## 交付自检

`tools/` 下的脚本覆盖了从本地到线上的每一道关卡：

| 脚本 | 作用 |
| --- | --- |
| `audit_site.py` | 本地：引用是否全为相对路径、目标是否存在、页面是否互达 |
| `qa_mobile.py` | 真机窄屏（390px）与桌面（1440px）逐页测量：横向溢出、破图、图片解码 |
| `shoot.py` / `shoot_mobile.py` | 桌面与窄屏截图，用于视觉走查 |
| `verify_live.py` | 公网抓取：页面状态码、每个资源的状态码、绝对路径泄漏 |
| `final_check.py` | 线上验收：页面、资源、路径、行尾、首页链接、外链依赖 |

窄屏检查需要特别说明：Edge 无头模式会把窗口宽度钳制在约 504px，
用 `--window-size=390` 截出来的其实是一张 504px 版面再裁切到 390px 的假图。
`qa_mobile.py` 改用固定宽度的 iframe 渲染，得到真正的 390px 视口，
因此报告里的 `innerWidth` 与溢出数据是可信的。
